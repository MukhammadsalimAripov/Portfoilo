# Next.js Портфолио — Мухаммадсалим

Современное веб-портфолио, разработанное на **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, с поддержкой **двуязычности (UZB / RU)**, **тёмной и светлой темы (Dark / Light mode)**, **интерактивным счётчиком проектов** и **парольной защитой панели администратора**.

---

## ⚡ Быстрый запуск

В терминале в папке проекта выполните:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev
```

После этого откройте в браузере: **[http://localhost:3000](http://localhost:3000)**

---

## 🔑 Доступ для администратора

- Кнопка **«Только для администратора»** (в шапке, герое, подвале и на странице проектов).
- Пароль администратора: **`MUKHAMMADSALIMARIPOV`**
- После ввода пароля открывается страница **/admin**, где можно:
  - Добавлять новые проекты с названием, описанием, стеком технологий, ссылками на демо и GitHub.
  - Загружать обложки проектов как ссылкой (URL), так и напрямую файлом с устройства.
  - Удалять проекты в 1 клик.
  - Восстанавливать демонстрационные проекты.

## 🌟 Страницы и функционал

1. **Главная страница (`/`)**:
   - Приветствие: *«Здравствуйте, меня зовут Мухаммадсалим, я веб-разработчик»* / *«Assalomu alaykum, mening ismim Muhammadsalim, men veb-dasturchiman»*.
   - Кнопка **«Смотреть проекты»** с переходом на `/projects`.
   - Кнопка **«Только для администратора»** с проверкой пароля `MUKHAMMADSALIMARIPOV`.
   - Блоки «Обо мне», «Навыки» (Frontend, Backend, DevOps) и контактная форма.

2. **Страница проектов (`/projects`)**:
   - **Интерактивный счётчик проектов**: Всего проектов, Frontend, Fullstack, E-Commerce & Bots.
   - Поиск по названию и технологиям.
   - Фильтры по категориям.
   - Детальный просмотр каждого проекта.

3. **Панель администратора (`/admin`)**:
   - Защищена авторизацией по паролю `MUKHAMMADSALIMARIPOV`.
   - Полное управление проектами.

4. **Мультиязычность (RU / UZB)**:
   - Переключатель в шапке сайта.
   - Мгновенный перевод интерфейса.

5. **Темы (Dark / Light)**:
   - Переключатель тёмного и светлого режима с сохранением в `localStorage`.

## 📁 Структура проекта Next.js

```
portfoilo/
├── app/
│   ├── layout.tsx             # Корневой макет с провайдерами темы и языка
│   ├── page.tsx               # Главная страница (Обо мне, приветствие, навыки)
│   ├── globals.css            # Стили Tailwind и кастомные анимации
│   ├── projects/
│   │   └── page.tsx           # Каталог проектов со счётчиком и фильтрами
│   └── admin/
│       └── page.tsx           # Панель администратора (защищена паролем)
├── components/
│   ├── Navbar.tsx             # Навигация, смена языка и темы, кнопка админа
│   ├── Footer.tsx             # Подвал сайта
│   ├── HeroSection.tsx        # Главный экран
│   ├── AboutSection.tsx       # Обо мне
│   ├── SkillsSection.tsx      # Технологии
│   ├── ContactSection.tsx     # Форма контактов
│   ├── AdminModal.tsx         # Модальное окно ввода пароля администратора
│   ├── ProjectCard.tsx        # Карточка проекта с модальным окном
│   ├── ProjectCounterBar.tsx  # Счётчик проектов по категориям
│   └── Providers.tsx          # Провайдеры Theme и Language Context
├── context/
│   ├── LanguageContext.tsx    # Контекст переключения языков RU/UZB
│   └── ThemeContext.tsx       # Контекст тёмной/светлой темы
├── lib/
│   ├── types.ts               # TypeScript типы
│   ├── translations.ts        # Словари переводов и пароль администратора
│   └── storage.ts             # Управление проектами и сессией админа
├── package.json               # Зависимости Next.js, React, Tailwind, Lucide
├── tsconfig.json              # Конфигурация TypeScript
├── tailwind.config.ts         # Конфигурация Tailwind CSS
├── postcss.config.mjs         # Конфигурация PostCSS
└── next.config.mjs            # Конфигурация Next.js
```
